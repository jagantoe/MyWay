MyWay

Bookmarklets that add features to the Azure DevOps web UI.

Install
  1. Show the bookmarks bar (Ctrl+Shift+B).
  2. Drag a blue button onto the bookmarks bar. Or click Copy bookmarklet, add a new bookmark and paste it into the URL field.
  3. Open the matching Azure DevOps page and click the bookmark.

Don't paste a bookmarklet into the address bar: browsers remove the javascript: prefix from pasted text. The raw source URL is meant for the DevTools console and development; use the bookmarklet for everyday use.
